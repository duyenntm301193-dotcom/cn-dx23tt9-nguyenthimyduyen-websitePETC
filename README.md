# cn-dx23tt9-nguyenthimyduyen-websitePETC

**Các file chưa trong Main và Master branch**
1. Main: 
Main chứa file progress report và file Readme. 
Main branch để cập nhật tiến độ và những thông tin cần thiết về dự án
2. Master: 
Master chứa file để chạy hệ thống. 
Folder Database trong branch master chứ file CSDL PETC_DB.sql

**Cách chạy CSDL**
1. MỞ SQL Server Management Studio
2. Execute PETC_DB.sql
3. Run project PETC_DB trong Visual Studio

**Phần mềm sử dụng**
1. SQL Server Management Studio. Link download: https://learn.microsoft.com/en-us/ssms/install/install
Dùng để: quản lý SQL Server, tạo database, chạy file .sql, xem bảng dữ liệu
2. SQL Server Express 2025. Link download: https://www.microsoft.com/en-us/sql-server/sql-server-downloads?msockid=3917f90e7d04629835a7ea8c7c5e63e7
Dùng để: Lưu database (database engine), website ASP.NET kết nối vào đây để đọc/ghi dữ liệu
3. Visual Studio Insiders. Link download:https://visualstudio.microsoft.com/insiders/
Khi cài hãy chọn download: ASP.NET and web development
